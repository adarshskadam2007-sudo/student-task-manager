# StudyFlow — Student Task Manager

A responsive student task manager built with **HTML, CSS, and vanilla JavaScript**. It helps students organize assignments, track deadlines, and prioritize study work.

## Features

- Create, edit, and delete tasks
- Set due dates, priority levels, and subject categories
- Mark tasks as complete and view completion statistics
- Filter tasks by all, due today, upcoming, or completed
- Search task titles, descriptions, and categories
- Sort by due date, priority, or recently added
- Saves tasks in browser Local Storage
- Responsive layout for desktop, tablet, and mobile
- Accessible form labels, keyboard-friendly dialog, and confirmation before deletion

## Live demo with GitHub Pages

After uploading the files to a GitHub repository:

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the deployment to finish. GitHub will show your live website URL in the Pages section.

## Run locally

Download or clone the repository and open `index.html` in your browser. No build tools or dependencies are required.

## Project files

- `index.html` — page structure and task form
- `style.css` — responsive design and styling
- `script.js` — task management, filters, sorting, and Local Storage
- `README.md` — project documentation

## Tech stack

- HTML5
- CSS3 (responsive layout and media queries)
- JavaScript (DOM events and Local Storage)
- GitHub Pages (deployment)

## Data and privacy

Tasks are saved only in the current browser using Local Storage. They are not synced between devices or sent to a server. Clearing browser site data may remove saved tasks.
